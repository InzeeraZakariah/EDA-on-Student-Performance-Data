# 📊 Exploratory Data Analysis on Student Performance Data

## 📌 Overview
This project performs **Exploratory Data Analysis (EDA)** on student performance data to uncover patterns and relationships between study habits, attendance, previous marks, assignments, backlogs, internet access, and academic outcomes (Pass/Fail).  
The goal is to identify key factors that influence student success and provide insights for academic improvement.

---

## 🚀 Features
- **Univariate Analysis**: Distribution of individual features (Age, Study Hours, Attendance, Marks, Assignments, Backlogs).
- **Bivariate Analysis**: Relationships between variables such as:
  - Study Hours vs Pass
  - Attendance vs Pass
  - Backlogs vs Pass
  - Internet Access vs Study Hours
- **Correlation Matrix**: Heatmap of numeric features to detect linear relationships.
- **Outlier Detection**: Identify anomalies in study hours and marks.
- **Group Comparisons**: Pass rates across backlog levels and internet access categories.

---

## 🛠️ Tech Stack
- **Python 3.9+**
- **Pandas** for data handling
- **Matplotlib & Seaborn** for visualization
- **NumPy** for numerical operations

---


## 📊 Key Insights
- Students with **higher study hours and attendance** tend to pass more often.  
- **Backlogs** are strongly associated with failure rates.  
- **Internet access** shows variation in study hours, potentially influencing performance.  
- **Outliers** (negative study hours, extremely high values) need cleaning before modeling.
